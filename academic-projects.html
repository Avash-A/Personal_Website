CMOS 8-Bit Adder VLSI Design

Transistor-Level Design, Simulation, and Physical Layout

Designed an 8-bit CMOS adder through a transistor-level VLSI design flow. The project began with circuit and logic development in LTspice and progressed to physical CMOS layout implementation in MicroWind, connecting schematic-level circuit behavior with integrated-circuit layout.

Design Flow

  1. Logic Design
  2. CMOS Transistor-Level Implementation
  3. LTspice Simulation
  4. Timing / Switching Analysis
  5. MicroWind Physical Layout
  6. Layout Review / Verification
  • 8-bit binary addition
  • CMOS
  • transistor sizing
  • propagation delay
  • rise/fall behavior
  • LTspice
  • MicroWind

Simple Educational Processor

HDL-Based Processor Architecture with Integer Operations and Branching

Developed and extended a modular SystemVerilog educational processor from a course starter structure. The design uses instruction and main-memory modules, internal registers, finite-state control, separate integer and matrix ALUs, opcode decoding, and conditional branch handling.

Implemented Architecture

  • fetch and decoded instruction fields
  • memory/register operand routing
  • integer add, subtract, multiply, and divide
  • matrix arithmetic datapath
  • BNE, BEQ, BLT, and BGT branches
  • active-low reset and clocked state sequencing
  • SystemVerilog
  • FSM control
  • opcode decoding
  • shared bus
  • integer ALU
  • branch control
