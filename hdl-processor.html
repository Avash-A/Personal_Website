SIMPLE EDUCATIONAL PROCESSOR

HDL-Based Processor Architecture

Project Overview

This project adapts and extends a course starter structure into a modular SystemVerilog educational processor. It fetches 32-bit instruction words, decodes opcode and operand fields, routes data among memory and internal registers, sequences separate arithmetic units, and updates instruction flow through conditional branches.

The supplied design supports integer arithmetic, matrix operations, memory/register operands, and BNE, BEQ, BLT, and BGT branch conditions. No standalone jump instruction or logical/bitwise instruction family is defined in the supplied source.

Processor Architecture

Instruction Memory

Stores the 32-bit instruction sequence and drives fetched instructions onto the bus when addressed.

Main Memory

Provides read/write storage for 256-bit data values through the shared address and control interface.

Execution Engine

Coordinates fetch, decode, operand movement, ALU sequencing, writeback, and conditional branch updates.

Matrix ALU

Implements supported matrix add, subtract, transpose, scale, and multiply operations.

Integer ALU

Implements integer add, subtract, multiply, and divide on the lower 16-bit operands.

Simulation Harness

Connects modules, generates clock/reset activity, records waveforms, and checks selected memory/register results.

Datapath

The design uses a 16-bit address bus and a shared 256-bit data path for main memory, internal registers, and ALU data movement. The execution module contains four 256-bit internal registers plus two temporary branch-operand registers. Instruction fetches use 32-bit words divided into opcode, destination, source-one, and source-two fields.

Control Logic

A clocked execution state machine sequences instruction-memory access, operand collection, ALU requests, and result writeback. Module-enable values in the upper address bits select instruction memory, main memory, execution-register access, the matrix ALU, or the integer ALU. Read and write controls coordinate which module drives the shared bus.

Instruction / Opcode Handling

Each instruction contains four 8-bit fields: opcode, destination, source one, and source two. Opcode families select matrix operations, integer operations, conditional branches, or stop. Operand encoding distinguishes main-memory locations from internal-register locations, and the matrix scale-immediate path treats the encoded source value as an immediate operand.

Integer Operations

  • Add
  • Subtract
  • Multiply
  • Divide with a zero-divisor guard

The integer ALU operates on the lower 16 bits of its two input registers and returns the result on the wider shared data path.

Branching & Program Flow

The execution engine buffers two operands for comparison and supports BNE, BEQ, BLT, and BGT conditions. A 12-bit instruction-sequencing counter advances during fetch and is adjusted forward or backward by the encoded branch offset when a condition is satisfied. The source does not implement a separate jump opcode.

Clock & Reset Behavior

The execution controller updates on the positive clock edge, while memory, ALU, and internal-register data-path blocks use the negative edge. An active-low reset initializes the controller state, instruction counter, decoded fields, internal storage, and bus-driving state.

// Matrix datapath for add, subtract, transpose, scale, and multiply operations.
module MatrixAlu(Clk,DataOut, address, nRead,nWrite, nReset);

  input logic nRead,nWrite, nReset, Clk;
  input logic [15:0] address;

  inout logic [255:0] DataOut;
  logic [15:0] matrices [0:1][0:3][0:3];

  logic ItsMe;
  logic [255:0] MatrixToOutput;

  logic [33:0] sum;

  always_ff @(negedge Clk or negedge nReset)
    begin
      if(!nReset)
        begin
          matrices <= '{default:'0};
          ItsMe<=0;
        end
      else if(address[15:12] == AluEn)
        begin
          ItsMe<=0;
          if (~nWrite)
            begin
              for (int i = 0; i < 4; i = i + 1)
    		    begin
        			for (int j = 0; j < 4; j = j + 1)
        			begin
                      matrices[address[3:0]][i][j] <= DataOut[((i*4+j)*16) +: 16];
        			end
    			end
            end
          if(~nRead)
            begin
                if(address[11:4] == MAdd)
                begin
                    for(int i = 0; i < 4; i = i + 1)
                    begin
                        for(int j = 0; j < 4; j = j + 1)
                        begin
                            MatrixToOutput[((i*4+j)*16) +: 16]
                                <= matrices[0][i][j]
                                 + matrices[1][i][j];
                        end
                    end
                end
              if(address[11:4] == MSub)
                begin
                    for(int i = 0; i < 4; i = i + 1)
                    begin
                        for(int j = 0; j < 4; j = j + 1)
                        begin
                            MatrixToOutput[((i*4+j)*16) +: 16]
                                <= matrices[0][i][j]
                                 - matrices[1][i][j];
                        end
                    end
                end
              if(address[11:4] == MTranspose)
                begin
                    for(int i = 0; i < 4; i = i + 1)
                    begin
                        for(int j = 0; j < 4; j = j + 1)
                        begin
                            MatrixToOutput[((i*4+j)*16) +: 16]
                                     <= matrices[0][j][i];
                        end
                    end
                end
              if(address[11:4] == MScale)
                begin
                    for(int i = 0; i < 4; i = i + 1)
                    begin
                        for(int j = 0; j < 4; j = j + 1)
                        begin
                            MatrixToOutput[((i*4+j)*16) +: 16]
                                <= matrices[0][i][j]
                                 * matrices[1][0][0];
                        end
                    end
                end
              if(address[11:4] == MScaleImm)
                begin
                    for(int i = 0; i < 4; i = i + 1)
                    begin
                        for(int j = 0; j < 4; j = j + 1)
                        begin
                            MatrixToOutput[((i*4+j)*16) +: 16]
                                <= matrices[0][i][j]
                         		 * matrices[1][0][0];
                        end
                    end
                end
              if(address[11:4] == MMult1)
                begin
                    for(int i = 0; i < 4; i = i + 1)
                    begin
                        for(int j = 0; j < 4; j = j + 1)
                        begin
                          sum=0;
                          for(int k=0; k<4; k++)
                            begin
                              sum+=matrices[0][i][k]*matrices[1][k][j];
                            end
                            MatrixToOutput[((i*4+j)*16) +: 16]
                          <= sum[15:0];
                        end
                    end
                end

                ItsMe <= 1;
            end
        end
       else
        ItsMe<=0;
    end


  assign DataOut= ItsMe ? MatrixToOutput : 256'bz;

endmodule

// Fetch/decode control, internal registers, branch handling, and datapath sequencing.
module Execution(Clk,DataOut, address, nRead,nWrite, nReset);
  output logic nRead,nWrite;
  input logic nReset, Clk;
  output logic [15:0] address;

  inout logic [255:0] DataOut;

  logic [255:0] InternalReg[3:0];
  logic ItsMe, InsMemRead;

  logic [255:0] MatrixToOutput;

  logic [2:0] State;
  logic [11:0] count;
  logic [2:0] AluStatus;

  logic [7:0] OpCode;
  logic [7:0] Destination;
  logic [7:0] Source1;
  logic [7:0] Source2;

  logic [255:0] registersForBranch [0:1];
  logic BranchEn;


  always_ff @(posedge Clk or negedge nReset)
    begin
      if(~nReset)
        begin

          address<=0;
          registersForBranch <= '{default:'0};
          BranchEn<=0;
          nRead<=1;
          nWrite<=1;
          State<=InstrMemEn;
          count<=0;
          InsMemRead<=0;
          OpCode<=0;
          Source2<=0;
          Source1<=0;
          Destination<=0;
        end


////////For Branching
      else if(BranchEn)
        begin
          if(OpCode==BNE)
            begin
              if(registersForBranch[0]!=registersForBranch[1])
                begin
                  if(Destination[7:4]==4'h0)
                    begin
                      count <= count + Destination[6:0];
                    end
                  else
                    begin
                      count <= count - Destination[6:0] - 1;
                    end
                end
            end
          else if(OpCode==BEQ)
            begin
              if(registersForBranch[0]==registersForBranch[1])
                begin
                  if(Destination[7:4]==4'h0)
                    begin
                      count <= count + Destination[6:0];
                    end
                  else
                    begin
                      count <= count - Destination[6:0] - 1;
                    end
                end
            end
          else if(OpCode==BLT)
            begin
              if(registersForBranch[0]<registersForBranch[1])
                begin
                  if(Destination[7:4]==4'h0)
                    begin
                      count <= count + Destination[6:0];
                    end
                  else
                    begin
                      count <= count - Destination[6:0] - 1;
                    end
                end
            end
          else if(OpCode==BGT)
            begin
              if(registersForBranch[0]>registersForBranch[1])
                begin
                  if(Destination[7:4]==4'h0)
                    begin
                      count <= count + Destination[6:0];
                    end
                  else
                    begin
                      count <= count - Destination[6:0] - 1;
                    end
                end
            end
          State<=InstrMemEn;
          nRead<=1;
          nWrite<=1;
          BranchEn<=0;
        end


//////For Operation
      else if(OpCode!=8'hff)
        begin
          nRead<=1;
      	  nWrite<=1;


          case (State)
            InstrMemEn:
              begin
              address <= {InstrMemEn, count};
			  count <= count + 1;
              nRead<=0;
              State<=MainMemEn;
              AluStatus<=ALU_Source1;
              InsMemRead<=1;
              end
//////////////MainMemEn
            MainMemEn:
              begin
              if(InsMemRead==1)
           		 begin
              	 OpCode      <= DataOut[31:24];
			  	 Destination <= DataOut[23:16];
			  	 Source1     <= DataOut[15:8];
			  	 Source2     <= DataOut[7:0];
              	 InsMemRead<=0;
                 end
               else if(AluStatus==ALU_Source1)
                  begin
                    if(Source1[7:4]==4'h0)
                      begin
                    	address<={MainMemEn,4'h0, Source1};
                    	nRead<=0;
                    	State<=AluEn;

                      end
                    else if(Source1[7:4]==4'h1)
                      begin
                        if(OpCode[7:4]==4'h2)
                          begin
                            registersForBranch[0]<=InternalReg[Source1[3:0]];
                            AluStatus<=ALU_Source2;
                          end
                        else
                          begin
                        	address<={ExecuteEn,8'h0, Source1[3:0]};
                    		nRead<=0;
                    		State<=AluEn;
                          end
                      end
                  end
                else if(AluStatus==ALU_Source2)
                  begin
                    if(OpCode==8'h07)
                      begin
                        address<={ExecuteEn,4'h0,Source2};
                        nRead<=0;
                        State<=AluEn;
                      end
                    else if(Source2[7:4]==4'h0)
                      begin
                    	address<={MainMemEn,4'h0, Source2};
                    	nRead<=0;
                    	State<=AluEn;
                      end
                    else if(Source2[7:4]==4'h1)
                      begin
                        if(OpCode[7:4]==4'h2)
                          begin
                            registersForBranch[1]<=InternalReg[Source2[3:0]];
                            BranchEn<=1;
                            AluStatus<=ALU_Source1;
                          end
                        else
                          begin
                        	address<={ExecuteEn,8'h0,Source2[3:0]};
                       		nRead<=0;
                        	State<=AluEn;
                          end
                      end
                  end
                else if(AluStatus==ALU_Result)
                  begin
                    if(Destination[7:4]==4'h0)
                      begin
                    	address<={MainMemEn,4'h0, Destination};
                    	nWrite<=0;
                    	State<=InstrMemEn;
                      end
                    else if(Destination[7:4]==4'h1)
                      begin
                        address<={ExecuteEn,8'h0, Destination[3:0]};
                        nWrite<=0;
                        State<=InstrMemEn;
                      end
                  end
              end
//////////////Alu En
            AluEn:
              begin
                //for matirx
                if(OpCode[7:4]==4'h0)
                  begin
                	if(AluStatus==ALU_Source1)
                  	begin
                        begin
                    		address<={AluEn, OpCode, 4'h0};
                    		nWrite<=0;
                    		AluStatus<=ALU_Source2;
                    		State<=MainMemEn;
                        end
                  	end
                	else if(AluStatus==ALU_Source2)
                  	begin
                        begin
                    		address<={AluEn, OpCode,4'h1};
                    		nWrite<=0;
                    		AluStatus<=ALU_Result;
                        end
                  	end
                	else if(AluStatus==ALU_Result)
                  	begin
                    	address<={AluEn, OpCode, 4'h0};
                    	nRead<=0;
                    	State<=MainMemEn;
                  	end
                  end

                //FOR Branching
                else if(OpCode[7:4]==4'h2)
                  begin
                    if(AluStatus==ALU_Source1)
                      begin
                        registersForBranch[0]<=DataOut;
                        AluStatus<=ALU_Source2;
                        State<=MainMemEn;
                      end
                    else if(AluStatus==ALU_Source2)
                      begin
                        registersForBranch[1]<=DataOut;
                        AluStatus<=ALU_Source2;
                        State<=InstrMemEn;
                        BranchEn<=1;
                      end
                  end

                 //for int
                else if(OpCode[7:4]==4'h1)
                   begin
                     if(AluStatus==ALU_Source1)
                  	begin
                      address<={IntAlu, OpCode, 4'h0};
                    	nWrite<=0;
                    	AluStatus<=ALU_Source2;
                    	State<=MainMemEn;
                  	end
                	else if(AluStatus==ALU_Source2)
                  	begin
                      address<={IntAlu, OpCode,4'h1};
                      nWrite<=0;
                      AluStatus<=ALU_Result;
                  	end
                	else if(AluStatus==ALU_Result)
                  	begin
                      address<={IntAlu, OpCode, 4'h0};
                    	nRead<=0;
                    	State<=MainMemEn;
                  	end
                   end
              end
          endcase
        end
      else
        begin
          State<=InstrMemEn;
          nRead<=1;
          nWrite<=1;
        end
    end

  always_ff @(negedge Clk or negedge nReset)
begin
	if (~nReset) begin
	 InternalReg<='{default:'0};
     MatrixToOutput<='{default:'0};
      ItsMe<=0;
	end

  else if(address[15:12] == ExecuteEn) // talking to Instruction
		begin

			if (~nRead)begin
			  ItsMe = 1; // Only Drive Bus on read
              if(OpCode==8'h07 && AluStatus==ALU_Source2)
                begin
                  MatrixToOutput={244'h0,address[11:0]};
                end
              else
                begin
					MatrixToOutput = InternalReg[address[11:0]]; // data will 							remain on dataout until it is changed.
                end
			end
			if(~nWrite)begin
			ItsMe = 0; // only drive bus on read
              InternalReg[address[11:0]] <= DataOut;
			end
		end
    else ItsMe = 0;
end



 assign DataOut=ItsMe? MatrixToOutput : 256'bz;
endmodule

// Integer arithmetic datapath for add, subtract, multiply, and guarded divide.
module IntegerAlu(Clk,DataOut, address, nRead,nWrite, nReset);
  input logic nRead,nWrite, nReset, Clk;
  input logic [15:0] address;

  logic ItsMe;

  inout logic [255:0] DataOut;

  logic [255:0] integers [0:1];

  logic [255:0] IntToOutput;

  always_ff @(negedge Clk or negedge nReset)
    begin
      if(!nReset)
        begin
          integers <= '{default:'0};
          ItsMe<=0;
        end
      else if(address[15:12] == IntAlu)
        begin
          ItsMe<=0;
          if (~nWrite)
            begin
              integers[address[3:0]]<= DataOut;
            end
          if(~nRead)
            begin
              if(address[11:4] == Iadd)
                begin
                  IntToOutput<= {240'b0,
                    			integers[0][15:0] + integers[1][15:0]};
                end
              if(address[11:4] == Isub)
                begin
                  IntToOutput<= {240'b0,
                    			integers[0][15:0] - integers[1][15:0]};
                end
              if(address[11:4] == Imult)
                begin
                  IntToOutput<= {240'b0,
                    			integers[0][15:0] * integers[1][15:0]};
                end
