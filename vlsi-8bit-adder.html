CMOS 8-BIT ADDER VLSI DESIGN

LTspice Schematic to MicroWind Physical Layout

Project Overview

Designed an 8-bit CMOS adder through a transistor-level VLSI design flow. The work connected binary-adder logic and hierarchical circuit construction with transistor-level simulation and physical CMOS layout.

Design Objective

Develop a functional hierarchical 8-bit binary adder, evaluate its transistor-level switching behavior qualitatively, and translate the circuit into a physical layout while maintaining consistency between logic, schematic, and layout views.

Design Flow

  1. 1Logic Design
  2. 2CMOS Transistor-Level Implementation
  3. 3LTspice Simulation
  4. 4Timing / Switching Analysis
  5. 5MicroWind Physical Layout
  6. 6Layout Review / Verification

CMOS Implementation

Constructed the adder from CMOS logic-gate building blocks and organized the circuit hierarchically for multi-bit binary addition. The design work considered transistor sizing, gate implementation, signal propagation, and rise/fall behavior.

LTspice Simulation

Used LTspice to develop and simulate transistor-level circuit behavior, inspect switching waveforms, and evaluate qualitative propagation and timing behavior before progressing to layout.

MicroWind Layout

Translated the CMOS circuit into a physical IC layout in MicroWind, connecting schematic-level device behavior with geometric transistor placement, interconnect, and layout review. This project did not include fabrication, tape-out, or silicon measurement.
